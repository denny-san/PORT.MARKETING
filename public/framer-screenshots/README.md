## 🎯 Uso para Framer Marketplace

### Screenshot Principal
Usa `01-home-desktop.png` como imagen destacada principal.

### Screenshots Adicionales
Incluye 3-5 imágenes adicionales mostrando diferentes páginas:
- `02-about-desktop.png`
- `05-certifications-desktop.png`
- `06-contact-desktop.png`
- `01-home-mobile.png` (para mostrar responsive)

## 📝 Notas

- Todas las capturas fueron tomadas del sitio desplegado en producción
- Resolución: Desktop 1920x1080px, Mobile 375x667px
- Formato: PNG de alta calidad
- Fecha de captura: $(Get-Date -Format "yyyy-MM-dd")

## 🔄 Regenerar Capturas

Para regenerar las capturas, ejecuta:

```bash
npm run screenshots
```

O manualmente:

```bash
node screenshot-script.js
```

**Nota**: Asegúrate de que el sitio esté desplegado o el servidor local esté corriendo.
