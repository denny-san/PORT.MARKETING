# ✅ Checklist para Publicar en Framer Marketplace

## 📋 Antes de Enviar

### Código
- [ ] Proyecto compila sin errores (`npm run build`)
- [ ] No hay warnings en la consola
- [ ] Todas las dependencias están en package.json
- [ ] README.md completo y actualizado
- [ ] Código comentado donde sea necesario
- [ ] Variables de entorno documentadas

### Diseño
- [ ] Diseño responsive (móvil, tablet, desktop)
- [ ] Todas las imágenes cargan correctamente
- [ ] No hay enlaces rotos
- [ ] Tipografía consistente
- [ ] Colores accesibles (contraste adecuado)
- [ ] Animaciones funcionan correctamente

### Funcionalidad
- [ ] Todas las páginas son accesibles
- [ ] Navegación funciona correctamente
- [ ] Formularios funcionan (si aplica)
- [ ] Botones y enlaces funcionan
- [ ] Componentes interactivos funcionan
- [ ] Chat AI funciona o está deshabilitado correctamente

### Contenido
- [ ] Texto sin errores ortográficos
- [ ] Información de contacto actualizada
- [ ] Enlaces a redes sociales funcionan
- [ ] Imágenes optimizadas (tamaño razonable)
- [ ] Contenido de ejemplo o placeholder claro

## 📸 Assets para el Marketplace

### Imágenes Requeridas
- [ ] Screenshot principal (1920x1080px)
- [ ] Screenshot página Home (1920x1080px)
- [ ] Screenshot página About (1920x1080px)
- [ ] Screenshot página Certifications (1920x1080px)
- [ ] Screenshot móvil (opcional pero recomendado)
- [ ] Logo/Icono (512x512px)

### Texto para el Marketplace
- [ ] Título atractivo (máx. 60 caracteres)
- [ ] Descripción corta (máx. 160 caracteres)
- [ ] Descripción larga (500-1000 palabras)
- [ ] Tags/Keywords (5-10 palabras clave)
- [ ] Características destacadas (lista de 5-7 puntos)
- [ ] Precio definido

## 📦 Archivos a Incluir

- [ ] Código fuente completo
- [ ] package.json actualizado
- [ ] README.md
- [ ] FRAMER_README.md
- [ ] .gitignore
- [ ] Imágenes de ejemplo (si aplica)
- [ ] Archivo de licencia (si aplica)

## 🔍 Revisión Final

- [ ] Probar en diferentes navegadores (Chrome, Firefox, Safari)
- [ ] Probar en diferentes dispositivos
- [ ] Verificar velocidad de carga
- [ ] Verificar SEO básico (meta tags)
- [ ] Verificar accesibilidad básica
- [ ] Leer toda la documentación como usuario nuevo

## 📝 Información del Creador

- [ ] Nombre completo
- [ ] Email de contacto
- [ ] Portfolio/Website (opcional)
- [ ] Redes sociales (opcional)
- [ ] Bio corta (opcional)

## 🎯 Después del Envío

- [ ] Guardar copia del envío
- [ ] Anotar fecha de envío
- [ ] Estar disponible para responder preguntas
- [ ] Prepararse para posibles revisiones

## 💡 Tips Adicionales

- Precio competitivo pero justo
- Screenshots de alta calidad
- Descripción clara y honesta
- Responder rápido a preguntas
- Mantener la plantilla actualizada
