# Guía para Publicar en Framer Marketplace

## Pasos para Enviar tu Plantilla

### 1. Preparación del Proyecto

✅ Asegúrate de que:
- El proyecto compile sin errores (`npm run build`)
- Todas las imágenes estén incluidas
- El README esté completo
- No haya enlaces rotos
- El diseño sea responsive

### 2. Crear Cuenta en Framer

1. Ve a [framer.com](https://www.framer.com)
2. Crea una cuenta o inicia sesión
3. Accede al **Creator Dashboard**

### 3. Preparar Assets para el Marketplace

Necesitarás:
- **Screenshot principal**: 1920x1080px (imagen destacada)
- **Screenshots adicionales**: 3-5 imágenes mostrando diferentes páginas
- **Logo/Icono**: 512x512px
- **Descripción**: Texto atractivo (máx. 500 palabras)
- **Tags**: Palabras clave relevantes (portfolio, security, SOC, cybersecurity)

### 4. Subir la Plantilla

1. En el Creator Dashboard, haz clic en "Submit Template"
2. Completa el formulario:
   - **Nombre**: "SOC Analyst Portfolio"
   - **Categoría**: Portfolio / Business
   - **Precio**: Define tu precio
   - **Descripción**: Usa el texto del README
   - **Screenshots**: Sube las imágenes preparadas
   - **Archivo**: Sube el proyecto completo (ZIP)

### 5. Información Requerida

- **Título**: SOC Analyst Portfolio Template
- **Descripción corta**: Portfolio profesional para analistas de seguridad SOC
- **Descripción larga**: (Usa el contenido del FRAMER_README.md)
- **Características destacadas**:
  - 6 páginas completas
  - Diseño responsive
  - Componentes interactivos
  - Fácil personalización
  - Optimizado para SEO

### 6. Proceso de Revisión

- **Tiempo estimado**: 7-14 días
- Framer revisará:
  - Calidad del diseño
  - Funcionalidad técnica
  - Experiencia de usuario
  - Cumplimiento de requisitos

### 7. Después de la Aprobación

- Tu plantilla aparecerá en el Marketplace
- Recibirás 100% de los ingresos
- Podrás actualizar la plantilla cuando quieras
- Los compradores podrán contactarte

## Tips para el Éxito

1. **Precio competitivo**: Investiga precios similares
2. **Buenas imágenes**: Screenshots de alta calidad
3. **Descripción clara**: Explica bien las características
4. **Soporte**: Responde rápido a preguntas
5. **Actualizaciones**: Mantén la plantilla actualizada
